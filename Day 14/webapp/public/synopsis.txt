--------------------------------------------------------------------------------
DAY 14: MODULES, LOGIN TESTING AND PLAYWRIGHT EXECUTION
--------------------------------------------------------------------------------

The concepts covered on Day 14 focus on creating reusable modules, running
Playwright tests, executing login automation, understanding server dependency,
and analyzing test reports.

--------------------------------------------------------------------------------
1. MODULES IN JAVASCRIPT
--------------------------------------------------------------------------------
Files Created:

    cal.mjs
    op.mjs

Purpose:

- Export functions
- Import reusable logic
- Reduce duplicate code

--------------------------------------------------------------------------------
2. MJS FILES
--------------------------------------------------------------------------------
Extension:

    .mjs

Purpose:

- ES Modules support
- Uses import/export

Example:

    export function add(){}

--------------------------------------------------------------------------------
3. LOGIN AUTOMATION TESTING
--------------------------------------------------------------------------------
Playwright tested:

- Valid login
- Invalid login
- Input validation

--------------------------------------------------------------------------------
4. SERVER DEPENDENCY
--------------------------------------------------------------------------------
Before running tests:

Command:

    node index.js

Expected:

    App started on PORT:3000

Reason:

- Server must run before Playwright tests

--------------------------------------------------------------------------------
5. PLAYWRIGHT TEST EXECUTION
--------------------------------------------------------------------------------
Command:

    npx playwright test

Purpose:

- Run automated tests

--------------------------------------------------------------------------------
6. ERROR ANALYSIS
--------------------------------------------------------------------------------
Error:

    ERR_CONNECTION_REFUSED

Cause:

- Server not started

Solution:

    node index.js

--------------------------------------------------------------------------------
7. HTML REPORT
--------------------------------------------------------------------------------
Command:

    npx playwright show-report

Purpose:

- View passed/failed tests
- Screenshots
- Trace files
